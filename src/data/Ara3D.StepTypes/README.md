# Ara3D.StepTypes

Typed descriptors for every entity of the STEP AP242 edition 3 long form (2,140 entities), generated by
`tools/Ara3D.IfcTypeGen` (`StepCodeGenTest.TestGenerate`). A shared project: `Ara3D.Step.Entities` compiles it in,
as `Ara3D.Ifc.Entities` compiles `Ara3D.IfcTypes`. Only `Core.cs` is written by hand; never edit a `*.g.cs` file.

One AP242 layer reads AP203 and AP214 files as well: the three share the Part 42 (geometry, topology) and Part 43
(representation) entities, and every instance of the 88 u-blox AP203 and AP214 test files has a name declared here.
One known difference: AP214 derives `conversion_based_unit.dimensions` (the file writes `*`), AP203 and AP242 store it.

| File | Holds |
|---|---|
| `Core.cs` | `StepEntityType` (a descriptor), `StepAttribute<T>`, the root interfaces `IStepValue`, `IStepEntity`, `IStepSelect`, and `PositionOf` |
| `Entities.g.cs` | Per entity a sealed descriptor class with one `Instance`: `AdvancedFace.Instance.FaceGeometry` |
| `Interfaces.g.cs` | Per entity an interface extending its supertypes' interfaces and the SELECTs that list it; per SELECT an interface |
| `Enums.g.cs` | Per ENUMERATION an enum, items in Pascal case (`.B_SPLINE.` is `BSpline`) |
| `Schema.g.cs` | `StepSchema.Entities`, every descriptor |

Names are the EXPRESS names in Pascal case, so some meet common .NET names (`Path`, `Vector`, `Line`, `Plane`, `Circle`);
qualify the other one, or alias this namespace (`using S = Ara3D.StepTypes;`).

An attribute field covers every slot of the entity's simple-instance record, inherited slots included, in record order.
It carries two addresses: `Position`, the slot in that record, and (`Entity`, `OwnPosition`), the declaring entity and
the slot in its partial record, which is how a complex instance writes it. An attribute name two supertypes both
declare is qualified by the declaring entity: `CartesianTransformationOperator3d.Instance.RepresentationItemName` and
`.FunctionallyDefinedTransformationName`.
