BIM OpenData BOS Explorer Source

Look inside a BIM Open Schema file

A .bos file is a zip of Parquet tables: entities, parameters, relations, and geometry. This page reads one with the BIM Open Viewer's JavaScript loaders and lists its tables, shows their rows, and draws the model.
